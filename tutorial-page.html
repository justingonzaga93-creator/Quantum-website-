How to Install the add-ons

Simple step-by-step guide for Minecraft Bedrock

Follow these easy steps:

  1. Download the mod file from the main website or shop.
    Download Now
  2. Open your File Manager on your phone or PC.
  3. Locate the downloaded mod file (it usually ends with .mcaddon or .zip).
  4. Tap the three dots (⋮) next to the file and select Rename.
    Important:
    • If the file ends with .zip, change it to .mcpack.
    • If the file already ends with .mcaddon, just remove the .zip
  5. Tap the file. It should automatically open in Minecraft.
  6. In Minecraft, go to Settings → Global Resources (or Behavior Packs) and activate the mod.
💡 Tip: Make sure you have the latest version of Minecraft Bedrock Edition installed for best compatibility.
⚠️ Warning: Do not rename files incorrectly; Minecraft may not recognize the mod.
✅ You're all set!
Enjoy your new mod! 🎮
